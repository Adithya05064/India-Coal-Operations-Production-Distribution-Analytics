# India Coal Operations: Production & Distribution Analytics

An interactive **geospatial and business intelligence project** analyzing coal and lignite production across India. The project covers data cleaning in Excel, analytical modeling in Tableau, geographical mapping, and interactive dashboard development.

## 📌 Project Overview

The dataset contains **458 production mines** across **12 States/UTs and 52 districts** in India.

The analysis focuses on:

* State and district-wise production
* Opencast vs. Underground mining
* Public vs. private ownership
* Company-wise production
* Coal vs. lignite
* Geographical distribution of mines

## 🛠 Tools & Skills

* **Excel:** Data cleaning, standardization, validation, and preprocessing
* **Tableau Desktop:** Calculated fields, parameters, dashboard actions, filters, and visualizations
* **Geospatial Analysis:** Latitude/Longitude-based mine mapping and geographical visualization

## 🔄 Project Workflow

**Raw Dataset → Excel Cleaning → Data Preparation → Tableau Analysis → Interactive Dashboard → Insights**

### 1. Data Cleaning & Preparation — Excel

* Standardized State/UT and District names for consistent analysis.
* Checked and handled missing or inconsistent values.
* Prepared production, ownership, and mine-type fields for analysis.
* Formatted latitude and longitude values for geographical mapping.

### 2. Data Analysis — Tableau

* Analyzed production across states, districts, and companies.
* Compared production across Opencast, Underground, and Mixed mine types.
* Examined government and private ownership patterns.
* Compared coal and lignite production.
* Created calculated fields and parameters for dynamic analysis.
* Used dashboard actions to connect map selections with other visualizations.

### 3. Interactive Dashboard

The final Tableau dashboard combines **KPIs, geographical maps, charts, and interactive filters**.

**Dashboard 1 — Operational Map & KPIs**

* Maps the geographical distribution of production mines.
* Displays total mines, mining companies, and production metrics.
* Allows users to explore mining activity across different regions.

**Dashboard 2 — Production Analysis**

* Dynamically switches between State, District, and Company-level views.
* Compares mine types and ownership categories.
* Provides a detailed view of production distribution.

## 📈 Key Insights

* The dataset covers **458 production mines** across **12 States/UTs and 52 districts**.
* **36 mining companies/operators** are represented in the dataset.
